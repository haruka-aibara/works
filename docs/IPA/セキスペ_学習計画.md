## 方針

### セキュアプログラミング問題は避けずに得点源にする

Java 未経験だが、**午後で必要なのは言語としての Java ではなく、毎年繰り返し出る狭いイディオム集**（JDBC の書き分け、`request.getParameter`、`HttpSession`、Cookie 属性、フィールドとローカル変数の置き場所）。クラス設計もジェネリクスも出ない。他言語の経験があるなら数時間で埋まる範囲。

避ける選択（午後は3〜4問から2問選択）もできるが、取らない。理由は2つ。

- **年度をまたいで同じ型が繰り返し出る**ので、対策コストあたりの得点効率が一番高い
- Java 未経験・未対策で初回50%取れている。イディオムを入れれば得点源にできる

「言語を知らないから避ける」と決めると、残り問題が全部苦手分野だった回に詰む。

### 現行形式の過去問5回分は温存する

**令和5年度秋期から午後Ⅰ・午後Ⅱが「午後」150分・4問から2問選択に統合**された。科目B はこの形式そのままなので、通し演習に使えるのは**令和5年度秋期〜令和7年度秋期の5回分（20問）だけ**。しかも CBT 移行後は IPA が過去問を公開しない可能性がある。

- **フェーズ1の個別演習**：令和4年度以前の午後Ⅰ・午後Ⅱを使う。形式は違うが問題単位では同じ素材で、午後Ⅰは短いので1問ずつ回すのに向く
- **フェーズ3の通し演習**：令和5年度秋期以降の5回分を温存し、150分の時間配分を体に入れるのに使う

入手先は [参考リンク](セキスペ_参考リンク.md) の「過去問」。

### 科目B を主線、科目A-1 を毎日の積立で並行

科目B を先にやりたいという本人の希望に沿った形。根拠は3つ。

- **科目B の学習は科目A-2 を兼ねる**。逆は成り立たない（A-2 を暗記しても B は書けない）
- 記述力は知識が入ってから書けるようになるまでラグがあるので、早く始めるほど有利
- 手応えのある方をやるほうが5か月続く

ただし科目A-1 は別枠で並行させる。**セキュリティの深さが1点も効かない全分野30問**で、基準点60点の単純なゲート。応用情報から2年以上経っていて確実に錆びている。範囲固定・過去問の使い回し率が高く、必要なのは集中ではなく反復回数なので、**毎日20〜30分の積立**が効く。まとめてやると間に合わない。

科目B は「まとまった時間で1問通す」、科目A-1 は「隙間で回す」。性質が違うので競合しない。

### 要復習リストに入れるものを絞る

これまでは参考書を読んで怪しかった用語を全部入れていたが、**今後は演習で落として、かつ技術系のものだけ**を入れる。

法務・基準名・ガイドライン名（リストの法務30行など）は科目A の材料で、口頭説明で1つずつ潰すより**過去問の選択肢で何度も遭遇させるほうが速い**。リストに入れると管理コストのほうが高くつく。

リスト側に残す価値があるのは TLS・IPsec・DNS・認証といった技術系だけ。科目B で「なぜそれで防げるのか」を書かされる領域。

## 並行する試験：EXIN Agile Scrum Master

**10月末に受ける**。普段スクラムマスターをやっているので、**新しく知識を入れる試験ではなく、用語と出題の癖に合わせる試験**として扱う。

- 準備は**1週間・試験対策だけ**に絞る。サンプル問題を解いて、実務の言い方と EXIN の用語がずれるところだけ拾う
- 準備週は **10/24〜10/31**。科目B の10月分（累計8問）はその前の3週間で終わらせておく
- その週は科目B の演習を止めてよいが、**科目A-1 の毎日30問だけは止めない**

## フェーズ

後期の日程から逆算する。各フェーズの終わりに「到達していればよい状態」を置き、届いていなければ次のフェーズの配分を変える。

### フェーズ0：9/23〜9/30 — 抜けている現在地を埋める

- **科目A-1 を1回分、素で解く**。唯一の未測定。この点数が以降の配分の基準になる
- 科目A-1 の毎日回しを開始（[応用情報ドットコム](https://www.ap-siken.com/)の過去問道場で「おすすめ」＝過去10回分・全分野からランダム30問。A-1 は応用情報の午前から抜き出して出題されるため）

### フェーズ1：10/1〜12/31 — 科目B を主線に

- 科目B を週2〜3問（**令和4年度以前の午後Ⅰ・午後Ⅱから**。現行形式の5回分は温存）。**模範解答と自分の答案の差分を言語化する**のが本体
- 毎回「知らなかった」のか「知っていたが書けなかった」のかを仕分ける。前者だけリストに戻す。後者は書き方の問題
- 科目A-1 は毎日30問継続
- 科目A-2 は個別対策しない（8/24 時点で78%、基準点超え）

到達していればよい状態：

| 期限 | 科目A-1 | 科目B | ネットワーク |
|---|---|---|---|
| **10/31** | 道場で60% | 午後Ⅰを累計8問。Java イディオム（PreparedStatement、static とローカル変数、所有者チェック）を**答案で書ける** | 要復習リストの技術系（FTP・SNMP・DNS・TLS・IPsec）が**レベル2**（目的と仕組みを口で説明できる） |
| **12/31** | 道場で**70%** | 午後Ⅰ・Ⅱを累計20問、**平均65%**。「繰り返している落とし方」のうち2回以上のものが再発していない | 同じ範囲が**レベル3**（「なぜそれで防げるか」を書ける）。科目A-2 のネットワークも60%以上 |

### フェーズ2：1/1〜2/下旬 — 科目A に寄せる

- **1/27 に申込。開始日に予約を取る**（CBT は枠の取り合いになる可能性）
- 科目A-1 の総仕上げ。**過去5回分を通しで安定して70%超え**
- 科目A-2 を過去問で確認し75%以上を維持。**法務・基準名の暗記に手を付けるのはこのタイミング**
- 科目B は週1問に落として感覚だけ維持
- 受験は 2/28〜3/2 の枠を狙い、準備期間を最大化

### フェーズ3：科目A 翌日〜3/中旬 — 科目B に全振り

- 科目A が終わっているので全時間を B に投入
- **『SC こう書く！』を使うのはここ**。知識が入った後に書き方を詰める段階
- **温存しておいた令和5年度秋期以降の5回分**を年度単位で通し、150分の時間配分を体に入れる。**選んだ2問がどちらも60%以上**で安定するのが到達点
- 受験は 3/20〜3/25 あたり

## 未確認

申込前に受験案内で確認する。

- **科目A が基準点未満だった場合、科目B は採点されるのか**。従来の筆記では午前Ⅰが基準点未満だと以降は採点されなかったが、日程が分かれた2026年度の CBT でどう適用されるか
- **科目A の結果は科目B の受験前に出るのか**

どちらも上のフェーズ計画は変わらない（いずれにせよ A を先に仕上げる必要がある）が、分かると気分の作り方が変わる。
