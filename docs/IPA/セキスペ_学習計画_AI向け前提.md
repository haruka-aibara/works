## 本人の前提

- **知らない・落とした用語は先に説明しない**（本人の指示）。用語を投げて本人に説明させ、足りないところだけ指摘する。手順は要復習リストの「復習の出し方」
- **所要時間から原因を決めつけない**（本人の指示、2026-11-23）。早く終わった＝見直していない、と書かない
- **忖度は一切しない**（本人の指示、2026-11-23）。遅れ・弱点・届かない見込みはぼかさずに言う。励ましの言い方はしない
- 2026-09-23 に、受験を前期から後期に切り替えた。後期は記述式で受けられる最後の回で、保険はない
- 2027年度から科目B は多肢選択式・120分・マネジメント強化に変わる
- 科目A-1 の免除はなし。応用情報の合格から2年以上経過している
- Java は書いたことがない。他言語の経験はあるので、`new` などの一般的な概念は分かる
- 参考書は2026年8月に1周完了
- 普段スクラムマスターをやっている。EXIN Agile Scrum Master を10月末に受けた（準備は 10/24〜10/31 の1週間）

### 科目B の初回演習で分かったこと（R5春 午後Ⅰ問1、2026-08-14）

穴埋め11箇所で正解5・部分正解1。基準点に届いていない。

落とし方に傾向がある。

- **概念名は書けるが、コードに落とせない**。「レースコンディション」は即答できたのに、原因（static フィールド）と対処（ローカル変数化）の穴埋めを両方落とした
- **JDBC の API が手に入っていない**。プレースホルダの理屈は説明できるのに `conn.createStatement()`（脆弱な側）と書いた
- **アクセス制御の観点が出てこない**。「注文番号だけで引ける＝他人の注文が見える」に気づかなかった

知識不足というより、「知っている概念を、コードと設計の言葉に変換する」経路がまだない状態。

## 方針の根拠

### 科目B を主線、科目A-1 を毎日の積立で並行

科目B を先にやりたいという本人の希望に沿った形。根拠は3つ。

- 科目B の学習は科目A-2 を兼ねる。逆は成り立たない（A-2 を暗記しても B は書けない）
- 記述力は、知識が入ってから書けるようになるまでラグがあるので、早く始めるほど有利
- 手応えのある方をやるほうが5か月続く

科目A-1 は、セキュリティの深さが1点も効かない全分野30問で、基準点60点の単純なゲート。
範囲固定・過去問の使い回し率が高く、必要なのは集中ではなく反復回数なので、毎日20〜30分の積立にした。
A-1 は応用情報の午前から抜き出して出題されるので、応用情報ドットコムの道場を使う。

科目B は「まとまった時間で1問通す」、科目A-1 は「隙間で回す」。性質が違うので競合しない。

### セキュアプログラミング問題は避けずに得点源にする

午後で必要なのは言語としての Java ではなく、毎年繰り返し出る狭いイディオム集。
JDBC の書き分け、`request.getParameter`、`HttpSession`、Cookie 属性、フィールドとローカル変数の置き場所。
クラス設計もジェネリクスも出ないので、他言語の経験があれば数時間で埋まる。

避けない理由は2つ。

- 年度をまたいで同じ型が繰り返し出るので、対策コストあたりの得点効率が一番高い
- Java 未経験・未対策で初回50%取れている

「言語を知らないから避ける」と決めると、残り問題が全部苦手分野だった回に詰む。

### 現行形式の過去問5回分は温存する

令和5年度秋期から、午後Ⅰ・午後Ⅱが「午後」150分・4問から2問選択に統合された。
科目B はこの形式そのままなので、通し演習に使えるのは令和5年度秋期〜令和7年度秋期の5回分（20問）だけ。
CBT 移行後は IPA が過去問を公開しない可能性もある。

そのため、個別演習には令和4年度以前の午後Ⅰ・午後Ⅱを使う。
形式は違うが問題単位では同じ素材で、午後Ⅰは短いので1問ずつ回すのに向く。

### 演習のやり方

- 模範解答と自分の答案の差分を言語化するのが本体
- 毎回「知らなかった」のか「知っていたが書けなかった」のかを仕分ける。前者だけ要復習リストに戻す。後者は書き方の問題
- 『SC こう書く！』は、知識が入った後に書き方を詰める3月に使う

### 要復習リストに入れるものを絞る

参考書を読んで怪しかった用語を全部入れるのはやめ、**演習で落とした技術系のものだけ**を入れる。
残す価値があるのは TLS・IPsec・DNS・認証といった、科目B で「なぜそれで防げるのか」を書かされる領域。

法務・基準名・ガイドライン名は科目A の材料で、口頭説明で潰すより過去問の選択肢で何度も遭遇させるほうが速い。
リストに入れると管理コストのほうが高くつくので、1月に科目A-2 の過去問で暗記する。

### 試験のルール（確認済み、2026-11-23）

申込前に確かめる予定だった3点は、CBT 運営会社の前期 FAQ で確認した。
詳細は [試験のルール](セキスペ_人間用/試験のルール.md)。

- 科目A が基準点未満でも科目B は受けられる。ただし全科目60点以上が合格条件なので不合格
- 科目A の得点は試験終了時に画面に出る。合否は実施期間終了後にまとめて発表
- 予約変更は試験日の3日前まで。キャンセル・返金・次回への充当は不可（体調不良でも）
