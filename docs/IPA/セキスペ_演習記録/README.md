## 記録の付け方

採点したら以下を全部やる。

1. **該当する試験回のファイルに節を追加**（なければ新規作成）。1問＝`## 問N — テーマ` の節
2. **この README の「演習した問題」に1行**追加（新しいものを上）
3. **「テーマ別」に1行**追加
4. **「繰り返している落とし方」を更新**。既にある落とし方なら回数を増やして出典を足す。新しいものなら行を足す
5. **取りこぼした技術系の用語は [要復習リスト](../セキスペ_要復習リスト/README.md) にも反映**する。ページ欄には出典を書く（例 `R5春午後Ⅰ問1`）。法務・基準名は反映しない（[学習計画](../セキスペ_学習計画.md)の方針）

### ファイル名の決め方

`<試験回>_<区分>.md`。区分は令和5年度春期までが `午後Ⅰ` / `午後Ⅱ`、令和5年度秋期以降は統合されたので `午後` のみ。

- `R5春_午後Ⅰ.md`
- `R5春_午後Ⅱ.md`
- `R5秋_午後.md`

### 1問あたりに書くこと

- **所要時間と持ち時間**（午後Ⅰは90分で3問中2問＝45分/問、現行の午後は150分で4問中2問＝75分/問）
- **設問別の正誤表**（設問 / 解答例 / 自分の解答 / ✓✗△）
- **落とした原因** — 何を知らなかったのか、知っていて書けなかったのかを分ける
- **覚え書き** — 次に同じ形が出たときに効く形にまとめる。コードや手順はそのまま書く
- **次に活かすこと** — 行動として書く
