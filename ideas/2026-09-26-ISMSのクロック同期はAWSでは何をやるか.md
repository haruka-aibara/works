# ISMS 8.17 クロックの同期は AWS では何をやるか

AWS で自分がやるのは EC2 の時刻源を Amazon Time Sync Service（`169.254.169.123`）に向けることだけ。マネージドサービスは AWS の責任範囲。

Ubuntu / RHEL の AWS 向け AMI が最初から向いているかは未確認。EC2 全台に Run Command（OS ごとにコマンドを変える）を流して、向いているか確認する。
