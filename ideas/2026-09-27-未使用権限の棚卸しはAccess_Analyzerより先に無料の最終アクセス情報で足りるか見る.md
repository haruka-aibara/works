# 未使用権限の棚卸しは、Access Analyzer より先に無料の最終アクセス情報で足りるか見る

IAM Access Analyzer の未使用アクセス分析は、分析するロール・ユーザー1つにつき月 $0.20。
単一アカウントでロールが数十個なら月数ドルだが、検出結果を誰も見なければ、ただの課金になる。

## 無料で見られるもの

- `generate-service-last-accessed-details`: サービス単位の最終アクセス。S3・EC2・IAM・Lambda などは Action 単位まで見られる
- credential report: アクセスキーとパスワードの最終使用日
- ロールの `RoleLastUsed`

## 判断

- 四半期に1回、人が棚卸しするだけなら、無料の情報をスクリプトで並べれば足りる
- Access Analyzer にお金を払う価値があるのは、検出結果を常時ためておき、ポリシーの修正案まで出してほしいとき
- どちらの場合も、検出結果は通知しない。棚卸しの日に見る

「純正でもできる」かではなく、無料側のスクリプトを誰が保守するかで比べる。
スクリプトが 50 行を超えそうなら、素直に払う。
