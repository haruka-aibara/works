# EC2 の公開系設定は SCP より宣言型ポリシーで固定する

IMDSv2 の強制・AMI の公開禁止・EBS スナップショットの公開禁止・VPC Block Public Access。
これまで SCP で「その API を Deny する」形で書いていたものは、Organizations の宣言型ポリシー（declarative policies）に寄せたほうが素直では。

## SCP と何が違うか

- SCP は API 呼び出しを止める。同じ状態を作れる別の API や、後から増えた API があると穴になる
- 宣言型ポリシーは「アカウントの設定値」そのものを固定する。メンバーアカウントの管理者が設定を変えようとしても変わらない
- 拒否時のエラーメッセージを自分で書ける。申請窓口を案内できる

## 気をつけること

- IMDS のデフォルト設定は新規起動にしか効かない（はず）。既存分は Config で見つけて直す
- VPC Block Public Access は必要な公開まで止まる。除外の設計を先に決める
- 対象は今のところ EC2 まわりだけ。S3 の公開封鎖は従来どおり [S3パブリックアクセスを組織全体で封鎖する](<../docs/Amazon Web Services/04_セキュリティ/データ保護/S3パブリックアクセスを組織全体で封鎖する.md>)

対象の設定項目は公式ドキュメント未確認。
