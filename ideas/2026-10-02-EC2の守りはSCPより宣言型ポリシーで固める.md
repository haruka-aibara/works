# EC2 の守りは SCP より宣言型ポリシーで固める

IMDSv2 強制や AMI の公開共有禁止を SCP で書くと、API アクションの列挙になり、新しい API が増えるたびに穴があく。

Organizations の宣言型ポリシー（declarative policies）は、API ではなくサービスの設定状態として「こうであること」を宣言する。
EC2 側が設定として強制するので、どの API から来ても効く。

## 対象になる設定（2024 年末の発表時点）

- IMDS のデフォルト（IMDSv2 必須など）
- AMI のパブリック共有ブロック、許可した AMI 以外の起動禁止
- EBS スナップショットのパブリック共有ブロック
- VPC のパブリックアクセスブロック
- シリアルコンソールの無効化

違反時のエラーメッセージを自分で書ける。

## SCP との分担

- 宣言型ポリシーで書ける設定はそちらに寄せる
- それ以外のサービス・操作の禁止は従来どおり SCP。[SCP で組織の安全ネットを張る](../docs/Amazon%20Web%20Services/04_セキュリティ/IAM/SCPで組織の安全ネットを張る.md)
