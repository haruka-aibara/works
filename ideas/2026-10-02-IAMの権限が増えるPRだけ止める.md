# IAM の権限が増える PR だけ止める

IAM ポリシーの差分を人間が毎回読むのはつらい。
IAM Access Analyzer の「カスタムポリシーチェック」を CI で叩けば、権限が増えたかどうかだけを機械的に判定できる。

## 使う API

- `check-no-new-access`：変更前と変更後のポリシーを渡すと、新しいアクセスが増えたかを返す
- `check-access-not-granted`：「`iam:PassRole` と `s3:DeleteBucket` は許さない」のような禁止リストに引っかかるかを返す
- `check-no-public-access`：リソースポリシーが公開になっていないかを返す

## 流れ

1. `terraform plan -out` → `terraform show -json` で変更前後のポリシー JSON を取り出す
2. 上の API に渡す
3. 増えていたら PR に「権限が増えています」とだけ書き、レビュー必須にする

増えていない PR（削る・リネームだけ）は人間が IAM を読まなくて済む。
レビューの重さを、権限が増える PR だけに寄せられる。

- 1 回ごとに課金がある。PR ごとに全ポリシーを投げず、差分のあったものだけ投げる
- AWS の資格情報が CI に要る。CI の OIDC ロールに閉じる
