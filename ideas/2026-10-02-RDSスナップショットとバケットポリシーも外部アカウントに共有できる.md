# RDS スナップショットとバケットポリシーも外部アカウントに共有できる

[スナップショットと AMI の持ち出し](2026-10-02-スナップショットとAMIの持ち出しは公開ブロックでは止まらない.md) と同じ構図が、RDS と S3 にもある。
「全員に公開」は止められても、**攻撃者のアカウント ID を名指しする共有**は公開ではないので止まらない。

## RDS スナップショット

`ModifyDBSnapshotAttribute`（クラスターは `ModifyDBClusterSnapshotAttribute`）で攻撃者に共有して持ち出す。
使っていないなら Deny する。

## S3 バケットポリシー

`Principal` に攻撃者のアカウントを書けば読まれる。パブリックアクセスブロックは素通りする（はず）。

- Terraform の実行ロール以外の `s3:PutBucketPolicy` を Deny
- 組織なら RCP で `aws:PrincipalOrgID` に絞れば、外部アカウントを書かれても効かない
- SSE-KMS（カスタマー管理キー）なら、キーポリシーも書き換えないと相手は読めない。SSE-S3 なら素通り

## 気づく側

IAM Access Analyzer の外部アクセス検出が、外部に開いたバケットやスナップショットを拾う（はず）。

公式ドキュメント未確認。
