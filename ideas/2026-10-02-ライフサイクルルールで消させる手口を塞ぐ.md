# ライフサイクルルールで消させる手口を塞ぐ

攻撃者が、盗んだクレデンシャルでバケットに「1 日後に全部期限切れ」のライフサイクルルールを仕掛け、
**AWS 自身に削除させてから**身代金を要求する手口がある。
消すのは S3 の内部処理なので、`DeleteObject` の Deny では止まらない。

[SSE-C を Deny する](2026-10-02-使っていないならSSE-CをDenyしておく.md) と同じ「S3 を人質に取る」系で、組で塞ぐ。

## 塞ぎ方

ライフサイクルルールは Terraform でしか変えない前提にして、
バケットポリシーで Terraform の実行ロール以外の `s3:PutLifecycleConfiguration` を Deny する。

```json
{
  "Effect": "Deny",
  "Principal": "*",
  "Action": "s3:PutLifecycleConfiguration",
  "Resource": "arn:aws:s3:::example-bucket",
  "Condition": {
    "ArnNotEquals": { "aws:PrincipalArn": "arn:aws:iam::111122223333:role/terraform" }
  }
}
```

## 気をつけること

- 実行ロールを盗まれたら素通り。最後の砦は Object Lock で、保持期間中は期限切れでも消えない（はず）
- バージョニングがあれば現行の期限切れは削除マーカーになるだけ。旧バージョンの期限切れまで仕掛けられると消える

手口の報告元と Object Lock との関係は公式ドキュメント未確認。
