# 使われていない権限を Access Analyzer の未使用アクセス検出で削る

IAM Access Analyzer の未使用アクセスアナライザーは、一定期間使われていないロール・アクセスキー・パスワード・権限を検出として出す。
最小権限は「最初から絞る」より「使われていないものを削る」ほうが現実的に回る。

## 削る順番

1. 使われていない IAM ユーザーのアクセスキー・パスワード：消すだけ。影響が読みやすい
2. 使われていないロール：消す前に CloudTrail で引き受け元を確認する
3. ロールの中の使われていない権限：検出にポリシーの推奨が出るので、Terraform に反映して PR を出す

3 は AI に向いている。検出の JSON を渡して Terraform に反映させ、PR まで作らせる。

## 気になる点（未確認）

- IAM の「最終アクセス」情報でも手でできる。差は、組織全体を横断して検出として並べてくれることと、推奨ポリシーまで出ること
- ロール・ユーザーの数で月額がかかる
- 年1回しか動かないロール（DR・監査用）を消さないよう、除外の仕組みが要る
