# 攻撃者は検知を止めるか、黙らせる

侵入した攻撃者は、まず検知を潰しにくる。
やり方は 2 つあり、**黙らせるほうは「止まった」アラートに引っかからない**。

| | 手口 |
|---|---|
| 止める | GuardDuty の detector 削除、Config のレコーダー停止、Security Hub CSPM の無効化、CloudTrail の `StopLogging` |
| 黙らせる | GuardDuty の信頼済み IP リストに自分の IP を足す・自動アーカイブのフィルタを作る、CloudTrail のイベントセレクタで記録対象を減らす、Security Hub CSPM の自動化ルールで finding を抑制済みにする、EventBridge の通知ルールを無効にする |

## 塞ぐ

どちらも Terraform の実行ロール以外は Deny する。黙らせる側を見落としやすい。

## 鳴らす

- GuardDuty は自分を消されたら何も言えない。止まったことの検知は別経路に置く
- 上の API を CloudTrail から EventBridge で拾って鳴らす
- 通知ルール自体の変更も鳴らす

## 組織なら

委任管理者から管理していれば、メンバー側では止められない（はず）。
SCP で止める・黙らせる操作を Deny する。

API 名と委任管理者配下の挙動は公式ドキュメント未確認。
