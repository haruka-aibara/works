# 攻撃者は検知を止めるか、黙らせる

侵入した攻撃者は検知を潰しにくる。**黙らせるほうは「止まった」アラートに引っかからない**。

| | 手口 |
|---|---|
| 止める | GuardDuty の detector 削除、Config のレコーダー停止、Security Hub CSPM の無効化、CloudTrail の `StopLogging` |
| 黙らせる | GuardDuty の信頼済み IP リストや自動アーカイブのフィルタ、CloudTrail のイベントセレクタを減らす、Security Hub CSPM の自動化ルールで抑制、通知ルールの無効化 |

## 塞ぐ

どちらも Terraform の実行ロール以外は Deny。黙らせる側を見落としやすい。

## 鳴らす：まずマネージド

- GuardDuty の `Stealth:IAMUser/CloudTrailLoggingDisabled` が CloudTrail の停止を、`DefenseEvasion:IAMUser/AnomalousBehavior` が `StopLogging` `DeleteFlowLogs` などの「消す・止める」系の異常な呼び出しを拾う
- 後者は ML で「その主体にとって異常か」を見るので、ふだん使う主体だと鳴らない
- GuardDuty は自分を消されたら言えない。detector 削除と「黙らせる」側は、CloudTrail を EventBridge で拾って鳴らす

## 組織なら

委任管理者から管理すればメンバー側では止められない。SCP でも Deny する。

委任管理者配下の挙動は未確認。
