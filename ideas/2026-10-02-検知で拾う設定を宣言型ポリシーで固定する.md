# 検知で拾う設定を宣言型ポリシーで固定する

Organizations の宣言型ポリシー（declarative policies）は、EC2 まわりの設定をサービス側で固定する。
SCP が「API を止める」のに対して、こちらは「設定そのものを、その状態にしておく」。

対象（2026年時点で自分が把握している範囲、未確認）：

- IMDSv2 の強制
- AMI・EBS スナップショットのパブリック共有のブロック
- シリアルコンソールの無効化
- VPC のブロックパブリックアクセス

## 何がうれしいか

どれも Security Hub CSPM や Prowler でよく鳴る項目。
宣言型ポリシーで固定すれば、新しいアカウントでも最初から準拠した状態になり、**検知自体が出なくなる**。
「通知が多いアラートから予防で潰す」の、いちばん安い打ち手になる。

## 試すこと

- 有効にしたあと、既存の非準拠リソースがどうなるか（止まるのか、新規だけ効くのか）
- 違反した利用者に返るエラー。カスタムメッセージを出せるはず
- Terraform の `aws_organizations_policy`（type = `DECLARATIVE_POLICY_EC2`）で持てるか
