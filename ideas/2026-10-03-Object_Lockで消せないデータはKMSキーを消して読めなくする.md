# Object Lock で消せないデータは KMS キーを消して読めなくする

Object Lock の compliance モードは、保持期間中は誰にも消せない。
個人情報や機密情報が混ざると、削除を求められても消せない。

そこで、オブジェクトではなく**鍵を消す**（暗号消去、crypto-shredding）。
オブジェクトはロックされたまま残るが、二度と読めない。

## やり方

1. ロックするバケットを SSE-KMS の CMK で暗号化しておく
2. 消す必要が出たら、残したい部分だけを別バケットに別の鍵で複製する
3. 元の CMK に `ScheduleKeyDeletion` をかける。待機期間（7〜30 日）後に読めなくなる

## 鍵の粒度 = 消せる単位

鍵を 1 本消すと、その鍵で暗号化したものが全部読めなくなる。

- 期間ごと（月ごとなど）に鍵を分ければ、巻き込む範囲がその期間だけになる
- 利用者ごとに分けたいなら、KMS キーは 1 本ごとに月額がかかるので、アプリ側のデータキーで暗号化してデータキーを消す

## 気をつけること

- `ScheduleKeyDeletion` はキーポリシーで限られたロールにだけ許す
- 複製先に個人情報が残っていないか確かめてから鍵を消す

暗号消去が法令上の「削除」と認められるかは未確認。
