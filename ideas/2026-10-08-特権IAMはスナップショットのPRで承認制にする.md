# 特権 IAM はスナップショットの PR で承認制にする

特権を持つロールやユーザーを自動で見つけ、確認して OK を出し、変わったらまた気づく。

## やること

GitHub Actions で毎日、全ロールと全ユーザーのポリシーを取る。
特権に当たるステートメントがあるものだけ、JSON を private リポジトリに書き出す。
main と差分があれば、固定のブランチで PR を作る。**マージが承認**。

- 記録するのは、信頼ポリシーの全文と、特権に当たるステートメントだけ
- 判定は `Action` を危険な操作の一覧と `fnmatch` で照らし合わせるだけ。条件や Deny は考えず、多めに拾う
- AWS 管理ポリシーも同じ扱い。AWS の更新で特権が増えたときだけ差分に出る
- Slack 通知は、PR を作ったときと中身が変わったときだけ

## はまりどころ

- 公開リポジトリには置かない。狙うべきロールの一覧になる
- ジョブの失敗も通知する。黙って止まると、変更がないのと見分けがつかない
- 侵入の検知ではない。作ってすぐ消された特権は残らない
