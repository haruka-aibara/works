# 特権 IAM はスナップショットの PR で承認制にする

特権を持つロールやユーザーを見つけて OK を出し、変わったらまた気づく。

## やること

private リポジトリの GitHub Actions が毎日、OIDC で AWS の Lambda を呼ぶ。
Lambda が全ロールと全ユーザーを読み、特権に当たるものを main の JSON と比べ、PR の操作まで決めて返す。
Actions はその指示どおりに、リソースごとのブランチで PR を作るだけ。**マージが承認**。

- 記録するのは、信頼ポリシーの全文と、特権に当たるステートメントだけ
- 判定は `Action` を危険な操作の一覧と `fnmatch` で照らすだけ。多めに拾う
- AWS 管理ポリシーも同じ扱い。特権が増えたときだけ差分に出る
- Slack 通知は、PR を作ったときと中身が変わったときだけ

## はまりどころ

- 公開リポジトリに置かない。狙うロールの一覧になる
- Actions に許すのは Lambda の呼び出しだけ。読む範囲と判定は Lambda 側に固定する
- ジョブの失敗も通知する。黙って止まると、変更がないのと見分けがつかない
- 侵入の検知ではない。即時はあとから EventBridge で起動する
