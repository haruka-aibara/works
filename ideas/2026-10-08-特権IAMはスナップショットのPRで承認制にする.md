# 特権 IAM はスナップショットの PR で承認制にする

特権を持つロールやユーザーを見つけ、確認して OK を出し、変わったらまた気づく。

## やること

EventBridge Scheduler で毎日 Lambda を動かし、全ロールと全ユーザーのポリシーを取る。
特権に当たるステートメントがあるものだけ、JSON を private リポジトリに書き出す。
main と差分があれば、固定のブランチで PR を作る。**マージが承認**。

- 記録するのは、信頼ポリシーの全文と、特権に当たるステートメントだけ
- 判定は `Action` を危険な操作の一覧と `fnmatch` で照らすだけ。多めに拾う
- AWS 管理ポリシーも同じ扱い。特権が増えたときだけ差分に出る
- Slack 通知は、PR を作ったときと中身が変わったときだけ

## はまりどころ

- 公開リポジトリに置かない。狙うロールの一覧になる
- GitHub へは GitHub App で書き込み、対象リポジトリと権限を絞る
- Lambda の失敗も通知する。黙って止まると、変更がないのと見分けがつかない
- 侵入の検知ではない。IAM のイベントで即時に動かすのは、あとから足す
