# 除外したロールの権限を check で確認時点に固定する

SCP やバケットポリシーの Deny から特定のロールを除外すると、除外は「どのロールか」にだけ効く。
あとから信頼ポリシーやアタッチしたポリシーが変わっても、除外は効き続ける。
信頼ポリシーを広げられると、引き受けられる全員が除外の対象になる。

## やること

確認した時点の権限を JSON でリポジトリに置き、Terraform の `check` ブロックで今の値と比べる。
変わっていれば、普段の plan に警告が出る。

- 信頼ポリシー：中身すべて
- アタッチした管理ポリシー：どれが付いているかと中身すべて
- インラインポリシー：付いていないこと

管理ポリシーは `aws_iam_policy` でデフォルトバージョンの中身を取る。
AWS が AWS 管理ポリシーを更新して広がった場合も気づける。
これは CloudTrail にも Terraform のドリフトにも出ない。

変更に問題がなければ、JSON を更新する PR を出す。それが再確認の記録になる。

コード・注意点・合わせてやることは [除外したロールの権限を check で固定する](../docs/Terraform/22_セキュリティ/22-07_除外したロールの権限をcheckで固定する.md)。
