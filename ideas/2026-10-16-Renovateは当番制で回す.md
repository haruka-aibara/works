# Renovate の PR は当番制で回す

依存の更新は大事だが急がないので、誰の仕事でもないまま放置される。
PR ごとに当番を 1 人ランダムで決めて、その人がレビューしてマージする。

- `renovate.json` の `assigneesFromCodeOwners: true` と `assigneesSampleSize: 1` で、CODEOWNERS のメンバーから 1 人をアサインする
- CODEOWNERS は当番の母集団として置くだけ。コードオーナーのレビュー必須はオンにしない
- 自動マージはしない
- Terraform の更新は 1 本にまとめて、当番が見る PR を減らす
- Slack の GitHub アプリで `renovate` ラベルの PR だけをチャンネルに流し、各自が `/github signin` しておくと、アサインが本物のメンションで届く

手順は [当番制とSlack通知](../docs/GitHub/41_Renovate/当番制とSlack通知.md) に書く。
