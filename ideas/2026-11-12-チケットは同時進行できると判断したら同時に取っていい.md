# チケットは同時進行できると判断したら同時に取っていい

スクラムでは「1人1チケットずつ、終わらせてから次」が基本。
でも手を動かすのが Claude なら、Claude のセッションを増やせば並べて進められる。
同時に進めて大丈夫と判断できたら、複数のチケットを同時に取っていいことにしてもいいのかもしれない。

## 同時に取っていいと判断する目安

- 触るファイルやリソースが重ならない（同じ Terraform の state や同じ設定ファイルなど）
- 前後の依存がない（片方の結果を見ないと、もう片方の作り方が決まらない、ということがない）
- 1チケット = 1セッション = 1ブランチで切れる

## 詰まりは人間の側に移る

セッションを増やしても、計画の承認とレビュー・マージは人間がやる。
並べすぎるとレビュー待ちの PR が溜まり、仕掛かりが増えるだけになる（Stop starting, start finishing）。
同時に取る数の上限は、人間がその日にレビューしきれる数で決める。

## デイリーで見るもの

「誰が何をやっているか」より「どのセッションの PR が誰のレビュー待ちか」。
止まっているセッションは、終わらせるか捨てるかをその場で決める。
