# S3 バケットは、参照を消してから消す

S3 のバケット名は世界で一意で、消すと**他人が同じ名前で作り直せる**。
消したバケット名がどこかに参照として残っていると、その参照は他人のバケットを指すことになる。

## 残りやすい参照

- CloudFront のオリジン
- アプリやスクリプトの設定ファイル、環境変数
- 他のサービスのログ出力先・エクスポート先
- ドキュメントや README に書いた URL

## 消す順番

1. 参照している箇所を洗い出して、先に消すか付け替える
2. 参照がなくなったことを確かめてから、バケットを消す

参照を洗い切れないなら、**バケットは消さずに空にして残す**のも手。
名前を持ち続けている限り、他人に取られない。

## 仕組みにする

- Terraform で消すなら、同じ PR で参照側も消えているかをレビューの観点に入れる
- 名前に推測しにくい接尾辞を付けておくと、消したあとに狙われにくい

新しく作るバケットの名前を、アカウント単位の名前空間に閉じる仕組みが S3 にあるかは未確認。
