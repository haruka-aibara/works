# Tailscale はハマチの今風版

やっていることはハマチ（LogMeIn Hamachi）と同じ。
離れた端末同士を、NAT 越しでも同じ LAN にいるようにつなぐ。
直接つながらなければ運営の中継サーバーを通るのも同じ。

違うのは中身と、入り方。

| | ハマチ | Tailscale |
|---|---|---|
| 暗号の仕組み | 独自プロトコル | WireGuard |
| 参加の仕方 | ネットワーク ID とパスワード | Google・GitHub などのアカウントでログイン |
| 誰がどこに届くか | 同じネットワークなら全部 | ACL でノード・ポート単位に絞れる |
| 振られるアドレス | `25.x.x.x` | `100.64.0.0/10` |
| 想定する使い方 | LAN ゲーム | サーバー・社内ネットワークへの接続 |

外向きの通信だけでつながるので、受信ルールを全部閉じたサーバーにも tailnet から届く。
