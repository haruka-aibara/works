# NCO の不正アクセス注意喚起は、基本の抜け・API・委託先を名指ししている

内閣官房国家サイバー統括室が 2026-11-05 に出した事業者向けの注意喚起。
Web サイトやモバイルアプリで個人情報を扱う事業者が対象。

## 原因とされたもの

最近の漏えい事案の原因として、次のような基本的な対策の不足が複数確認された。

- モバイルアプリ開発時の対策不足
- Web サイトなどの設定不備
- サポート切れや既知の脆弱性を放置したソフトの継続使用
- 自組織や委託先の基本的な対策の不足

攻撃者は日本のサイトなどを大規模に調査し、侵入できた所から盗んだとみられる。
AI を使っている可能性が高い。
「比較的低い」とされたリスクが組み合わさって侵入の原因になった可能性のある事例もあるので、低評価の指摘も放置しない。

## 担当者向けで押さえる点

- **露出の棚卸し**：管理画面、デバッグ用エンドポイント、検証環境が外から届く状態が実際に悪用された。LB や API ゲートウェイで、想定外のパスが裏に通らないかまで見る
- **悪用済みの脆弱性を先に**：CISA KEV を起点に照合する。ネットに出ているサーバーと機器を優先する
- **API**：アプリを解析してバックエンドを突く「A2B 攻撃」（NICT）が名指しされている。サーバー側の認可（BOLA / BFLA）、アプリに秘密を埋め込まないこと、レート制限
- **委託先**：保守用 VPN や RDP は「正規の認証情報で入れる入口」になる。MFA、終わった作業のアカウントの削除、委託開発での SBOM 提出
- **防御側の AI**：診断や監視に AI の活用を検討する。最終判断は人がする
