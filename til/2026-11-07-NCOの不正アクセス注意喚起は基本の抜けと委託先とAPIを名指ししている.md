# NCO の不正アクセス注意喚起は、基本の抜け・API・委託先を名指ししている

国家サイバー統括室が 2026-11-05 に出した、Web やアプリで個人情報を扱う事業者向けの注意喚起。
最近の漏えいの原因は、アプリ開発時の対策不足、設定不備、サポート切れ・既知脆弱性の放置、自社や委託先の基本対策不足とされた。

攻撃者は日本のサイトを大規模に調べて侵入しており、AI を使っている可能性が高い。
「低い」と評価されたリスクが組み合わさって侵入された可能性のある事例もある。

## 担当者として押さえる点

- **露出**：管理画面、デバッグ用エンドポイントの公開が悪用された。LB や API GW で想定外のパスが通らないかまで見る
- **脆弱性**：KEV など悪用済みのものから、ネットに出たサーバーと機器を優先する
- **API**：アプリを解析してバックエンドを突く A2B 攻撃（NICT）が名指しされている。サーバー側の認可、秘密をアプリに埋め込まない、レート制限
- **委託先**：保守用 VPN や RDP は正規の認証情報で入れる入口になる。MFA、不要アカウントの削除、SBOM の提出
- **AI**：診断や監視にも使うことを検討する。最終判断は人がする
